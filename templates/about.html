ARXİTEKTURA

N8n + FastAPI necə birlikdə işləyir

Sistem dörd sərbəst, amma bir-birinə bağlı hissədən ibarətdir: xəbər avtomasiyası n8n-də qurulub, bazar siqnalını FastAPI özü hesablayır, qərar və risk məntiqi hər iki halda Python backend-də saxlanılır, nəticə isə bu saytda göstərilir.

1. Xəbər təhlili workflow-u

n8n · Schedule + RSS + Groq AI + şəkil + Telegram

  1. Schedule Trigger — hər 6 saatdan bir işə düşür.
  2. RSS Read — federalreserve.gov rəsmi elanlarını çəkir.
  3. Limit — yalnız son 3 xəbəri götürür.
  4. Groq LLM (llama-3.1-8b-instant) — sərt JSON formatında xülasə, təsir edən cütlər, təsir dərəcəsi, istiqamət, etibar faizini Azərbaycan dilində qaytarır.
  5. Code node — JSON-u etibarlı şəkildə oxuyur, mövzuya uyğun şəkil üçün Pollinations.ai (pulsuz, açarsız) linkini qurur.
  6. POST /news/draft — qaralamanı (mətn + şəkil linki) bazada saxlayır, qısa bir id qaytarır.
  7. Telegram — şəkil + səliqəli Markdown mətn + /paylas <id> düyməsi kimi göndərilir. Heç nə avtomatik dərc olunmur.

2. Təsdiq və dərc workflow-u

n8n · Telegram Trigger + Code + HTTP Request

  1. Telegram Trigger — admin-in yazdığı mesajları dinləyir.
  2. Code node — mesaj /paylas <id> və ya /rədd <id> ilə başlayırsa id-ni çıxarır; uzun mətni yenidən yazmağa ehtiyac yoxdur, ona görə səhv/səliqəsiz kopyalama riski aradan qalxır.
  3. HTTP Request — POST /news/{id}/approve və ya /news/{id}/reject ünvanına göndərir.
  4. FastAPI — statusu DRAFT-dan PUBLISHED-ə keçirir, bu sayt Xəbərlər səhifəsində şəkli ilə birlikdə göstərir.
  5. Təsdiq mesajı — n8n admin-ə "dərc olundu / rədd edildi" deyə geri yazır.

3. RSI strategiya mühərriki

FastAPI · Frankfurter/ECB qiymətləri + Wilder RSI(14)

  1. Qiymət mənbəyi (app/market_data.py) — hər icazəli cüt üçün son ~60 günün gündəlik bağlanış qiymətini pulsuz, açar tələb etməyən Frankfurter/ECB API-dən çəkir.
  2. RSI(14) (app/strategies.py) — klassik Wilder düsturu ilə hesablanır.
  3. Qərar — RSI 30-dan aşağıdırsa BUY, 70-dən yuxarıdırsa SELL, aralıqda siqnal yoxdur (app/signal_engine.py).
  4. Avtomatik işə düşmə — backend başlayanda arxa fon tapşırığı hər 15 dəqiqədən bir özü yoxlayır (main.py); istəyə görə eyni işi n8n-dəki 3_rsi_signal_trigger_workflow.json ilə Schedule → HTTP Request formasında da tetikləmək mümkündür.
  5. Nəticə — yaradılan hər siqnal dərhal aşağıdakı risk zəncirindən keçir və dashboard-da canlı görünür; POST /signals/run-now ilə əl ilə də tetiklənə bilər (idarə panelindəki "Siqnalı indi yarat" düyməsi).

4. Risk zənciri və icra

FastAPI · Pydantic validasiya + risk qaydaları + icra

  1. POST /webhook/signal — istənilən mənbədən (n8n, TradingView, strategiya) gələn siqnal qəbul olunur və bazaya yazılır.
  2. Risk yoxlaması (app/risk.py) — icazəli cüt, maksimum həcm, məcburi stop-loss/take-profit, açıq mövqe limiti yoxlanılır.
  3. İcra (app/services.py) — PAPER rejimdə simulyasiya doldurulur; DEMO rejimdə (yalnız açıq şəkildə aktiv edilibsə) MetaTrader5 demo hesabına göndərilir. Real pul heç vaxt avtomatik risk alınmır.
  4. Dashboard — açıq mövqələr və son siqnallar canlı göstərilir.

Təhlükəsizlik prinsipləri

Bütün avtomatik qərarların arxasında insan nəzarəti var: xəbər heç vaxt birbaşa dərc olunmur, ticarət siqnalları Python tərəfində sərt risk qaydalarından keçir, sistem defolt olaraq PAPER (simulyasiya) rejimindədir və real order yalnız açıq şəkildə təsdiqlənmiş demo hesaba göndərilə bilər.
